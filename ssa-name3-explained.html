Chapter 3

The secret: how names become keys

Before any matching, each name is turned into several short search keys. Different spellings of the same name end up with the same keys. Values shown are illustrative.

Raw input
Mr. Billy O'Neil-Smyth Jr.
As typed
1 · Clean
MR BILLY ONEIL SMYTH JR
Case and punctuation
2 · Apply rules
WILLIAM ONEIL SMYTH
Drop titles; Billy → William
3 · Code sounds
WLM · ONL · SMT
Smyth and Smith become one
4 · Weigh rarity
O'Neil rare · William common
Rare words lead
5 · Make keys
ONL+SMT · SMT+WLM · ONL+WLM
Several per name
